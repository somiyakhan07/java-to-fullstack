# Conditional Statements in Java

This folder contains Java programs demonstrating conditional statements and decision-making constructs.

### Topics Covered

* `if` Statement
* `if-else` Statement
* `else-if` Ladder
* Nested `if` Statements
* `switch` Statement
* `switch` Expression

### Key Concepts

* Conditional execution
* Multiple condition evaluation
* Nested decision-making
* Logical and relational operators
* Menu-driven logic
* `switch` expressions with arrow syntax (`->`)
* Returning values from switch expressions using `yield`
* Multiple case labels
* Default cases for invalid input handling
