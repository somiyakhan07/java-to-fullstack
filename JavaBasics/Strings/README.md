# Strings in Java

This folder contains Java programs demonstrating string manipulation, comparison, searching, and problem-solving techniques in Java.

### Topics Covered

* String Creation and Initialization
* String Methods
* String Comparison
* String Searching
* String Reversal
* Palindrome Checking
* Character and Word Manipulation
* Character Frequency
* StringBuilder
* StringBuffer

### Key Concepts

* Working with immutable `String` objects
* Comparing strings using `equals()` and `equalsIgnoreCase()`
* Searching within strings
* Manipulating individual characters
* Reversing strings and checking palindromes
* Counting character occurrences
* Removing spaces and processing words
* Using mutable string classes such as `StringBuilder` and `StringBuffer`
